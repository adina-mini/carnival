# 💍 Wedding Invitation

A modern, elegant digital wedding invitation inspired by Pakistani wedding aesthetics, featuring a deep burgundy and gold color palette, subtle animations, and an interactive invitation experience.

## ✨ Features

- Minimal Pakistani wedding aesthetic
- Animated golden couple intro
- Elegant wedding details & event sections
- Responsive design for mobile and desktop
- Smooth transitions and micro-interactions
- Interactive RSVP experience

## 🛠️ Built With

- React
- Vite
- JavaScript
- CSS
